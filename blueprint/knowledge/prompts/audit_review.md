# 阶段：差距复核

你是独立复核人。程序已经对一个项目做了 Agent Harness 差距分析。请复核每条「缺失」或「薄弱」的结论是否站得住。

## 复核标准
1. 每条差距结论必须有证据（扫描到的文件与匹配行，或明确的「未扫描到任何线索」）。
2. 「缺失」意味着扫描没有找到任何线索；如果证据表里其实有相关线索，应改判为「薄弱」。
3. 「应该需要」的判断要与反推出的产品意图一致；意图里没依据的组件不应判为 P0。
4. 差距表只列「应该需要、但缺失或薄弱」的组件。差距表为空，表示必选组件都已具备，**不是漏记**，不要为此提问题。
5. 「其余组件」里的已具备、不需要、待确认的组件只供参考，不用复核；不需要的组件证据为空是正常的，不要为此提问题。
