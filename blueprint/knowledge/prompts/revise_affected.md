# 阶段：判断新需求涉及哪些方面

一个 Agent 产品已经有了一版方案，现在用户加了一条新需求。方案里的组件选型取决于下面这些特征的判断。
请判断：这条新需求会改变哪些特征的判断（从不需要变成需要、从需要变成不需要、从以后再做变成现在就做，或反过来）。

## 新需求
{requirement}

## 特征（id：问题）
{features}

## 要求
- 只选和这条新需求直接相关的特征；新需求没提到、也推不出来的，不要选。
- 拿不准的选上：选上的特征会结合整份需求重新判断，没选的会沿用上一版的判断。
- affected 里只能出现上面列出的 id。

## 输出 JSON 结构
{{"affected": ["scheduled"], "reason": "一句话说明"}}
