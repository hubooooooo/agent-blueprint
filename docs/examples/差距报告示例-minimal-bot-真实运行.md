## 它现在是什么

项目是一个只有 32 行的单文件 Python 脚本（src/bot.py），依赖 Anthropic SDK，从环境变量 MODEL_ID 读模型，注册了一个 bash 工具，用 while True 循环执行模型要求的 shell 命令。运行方式是终端里的 >> 提示符，反复喂用户输入、执行命令；没有审批、没有审计、没有错误处理、也没有会话持久化。值得注意的是，脚本从没把模型的最终文字回答打印出来，用户在终端唯一能看到的是自己输入的内容。README 只用一句话描述了意图，没有任何验收标准或使用说明。
