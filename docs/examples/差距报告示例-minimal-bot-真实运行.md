## 它现在是什么

这是一个体量极小的 Python 命令行项目，入口为 src/bot.py，依赖 Anthropic SDK 调用大模型。README 描述的产品形态是：运维工程师输入自然语言，机器人把它变成 shell 命令执行，再把结果汇报给用户。README 明确声明它可以执行删除文件、重启服务这类破坏性或敏感操作，但从扫描结果看，项目中没有任何审批、拦截、审计或权限限制的代码，也没有容错、可观测、可测试相关的基础设施。整体处于能跑通主流程的原型阶段，方向清晰但工程约束几乎空白。

## 需要项目作者回答的问题

1. 这个助手执行 shell 命令前，是否会先回显命令并要求运维工程师确认？
