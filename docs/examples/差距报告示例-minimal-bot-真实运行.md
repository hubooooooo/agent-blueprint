## 它现在是什么

这是一个极简的 Anthropic 官方 SDK 示例级项目，全仓库只有一个 src/bot.py（32 行）和一个 README。它维护一个 interactive 的 input 循环，把用户输入追加进 messages，然后进入 agent_loop：调用 messages.create，若响应里出现 tool_use 就执行 bash 工具并回填 tool_result，直到模型不再调用工具为止。工具只有 bash 一个，且用 subprocess.run(shell=True) 直接执行模型给出的任意命令。它没有任何权限、钩子、压缩、后台任务、审计或持久化机制，也没有测试、配置文件和依赖声明。
