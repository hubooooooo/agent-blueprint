## 建议下一步（按顺序做）

1. **缺失：s03 权限系统** —— 先划边界，再给自由。生产级要点：白名单/黑名单、破坏性操作二次确认、审计日志、默认拒绝。参考 `s03_permission/README.md`。
2. **加固：s01 Agent Loop** —— 最小可运行闭环。生产级要点：重试、超时、token 上限、`stop_reason` 完整处理。参考 `s01_agent_loop/README.md`。
3. **加固：s02 工具系统** —— 循环不变，工具可增。生产级要点：JSON schema 严格、参数校验、错误回传格式统一。参考 `s02_tool_use/README.md`。
4. **缺失：s04 钩子系统** —— 挂循环上，不写循环里。生产级要点：PreToolUse 可阻断、PostToolUse 可观察。参考 `s04_hooks/README.md`。
