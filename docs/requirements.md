# 项目范围与分发约定

## 当前用途

用户提供引擎文件夹位置和点子或目标项目路径，由能读取本地文件的 AI 按 [使用引导](../使用引导.md) 工作，交付方案或差距报告。

保留知识、规则、扫描、审稿、续跑、评估和命令行能力。前端、本地网页、账户、应用安装包不在项目范围；学生收到的是可解压的文件包。

当前 AI 按手册分析、程序模型管线执行、离线演示三者必须如实区分。未配置模型接口不能把演示输出当真实结论。

## 学生分发

- 使用 `python3 tools/package_student.py` 生成学生压缩包。
- 包含使用引导、蓝图、引擎、教学组件及图示、技能、scaffold、评估、测试、环境模板和初始化脚本。
- 排除 `.env`、`.venv/`、`.git/`、运行产物、缓存、个人配置与历史检查记录。
- 保留可移植的 `.vscode/` 引导配置；路径使用 `${workspaceFolder}`，不能绑定维护者电脑。
- 本地 `.env` 和 `.venv/` 留给维护者使用，不随包发送。依赖由 `setup.sh` 在学生电脑创建。
- 分发前在解压目录检查文档链接，运行离线评估和测试。
