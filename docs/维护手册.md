## 常用命令

在引擎根目录运行：

```sh
.venv/bin/python -m blueprint plan idea.md -o out/my-plan
.venv/bin/python -m blueprint audit /目标项目路径 --prd prd.md -o out/my-audit
.venv/bin/python -m blueprint plan idea.md -o out/my-plan --resume
.venv/bin/python -m blueprint eval
.venv/bin/python -m blueprint eval --real
.venv/bin/python -m pytest -q
```

`--mock` 为离线占位输出；`--model` 覆盖模型 ID；`--max-calls` 和 `--max-tokens` 限制新一轮运行的调用次数和 token 用量，不是金额硬上限。

## 修改规则与模型

- **改规则**：同步修改选型规则、特征表和 `evals/forward/*/expected.json`，再运行离线评估。
- **加组件**：补齐组件说明、特征映射、扫描信号及测试；不要仅凭关键词数量认定功能完整。
- **改提示词**：模板使用 `str.format`，字面花括号写成 `{{ }}`。改完需做真实输出质量检查，不能只看 JSON 是否合法。
- **改模型**：维护者在 `.env` 配置 `ANTHROPIC_API_KEY`、`MODEL_ID`，自定义 Anthropic-compatible 网关使用 `ANTHROPIC_BASE_URL`。环境变量优先于 `.env`。不要将密钥复制到手册或分发包。
- **失败续跑**：同一任务使用同一输出目录加 `--resume`。缓存核对输入、源码摘要、模型、提示词、schema 和上游结果，变更或损坏时重跑；写入使用原子替换。

## 验证边界

- 离线题库覆盖 3 个正向案例和 2 个反向案例；`eval --real` 当前只测正向需求拆解，完整方案和反向报告仍需真实验收。
- 扫描为正则启发式；业务代码命中至少 2 个文件或 4 行为 strong，1 个文件为 weak。文档和测试描述不计为实现，扫描跳过符号链接和依赖目录。
- 静态分数不能证明能力已集成，也不能替代运行测试；非 Python 入口与调用关系识别有限。
- 正向审稿失败会重写一次；审稿是同一模型的另一次调用。反向复核的输入覆盖仍需加强，尤其是用户 PRD 与反推意图不一致时。
- 真实请求超时 120 秒，关闭 SDK 隐式重试，JSON 纠错最多一次。token 护栏依据已返回用量阻止后续请求，续跑预算重新计算。

## 发给学生

```sh
python3 tools/package_student.py
```

生成 `dist/agent-blueprint-student.zip`。脚本按允许清单收集教学内容；未列入的本机文件不打包。包括 `.env.example`、`setup.sh` 和可移植的 `.vscode/` 配置，不包括真实 `.env`、`.venv/`、Git、缓存和 `out/`。

修改内容后重新生成压缩包；若增加了需要分发的文件类型或目录，同步调整脚本清单。分发前在解压副本运行离线评估、测试，并检查 Markdown 链接。MIT 许可证必须随包保留。
